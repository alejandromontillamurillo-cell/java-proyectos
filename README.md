# Prácticas y ejercicios de Java

Repositorio de aprendizaje con ejercicios de clase y prácticas independientes escritas en **Java**. La colección permite consultar ejemplos de programación y seguir la evolución de las actividades.

## Estructura

- `Ejercicios_clase/`: ejercicios organizados por tarea o unidad.
- `Practicas_java/`: prácticas independientes, pequeños programas y ejercicios de lógica.

Los nombres de los archivos identifican las actividades; cada clase puede ejecutarse por separado cuando contiene su propio método `main`.

## Requisitos y ejecución

Se necesita un JDK. Para probar una clase concreta, compílala desde su carpeta y ejecuta el nombre de la clase. Por ejemplo:

```bash
javac NombreDeLaClase.java
java NombreDeLaClase
```

Algunos ejercicios pueden requerir compilar también otras clases del mismo ejercicio. Consulta el código fuente correspondiente.

## Temas de práctica

Fundamentos de Java, control de flujo, métodos, clases, entrada/salida y resolución de problemas. Es una colección formativa, no un único producto instalable.
