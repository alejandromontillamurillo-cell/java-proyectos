# 🌐 Java Projects and Assignments

Repository dedicated to the development, organization, and documentation of Java programming exercises and assignments.

This repository contains practical activities focused on learning Java, understanding Object-Oriented Programming (OOP) concepts, and mastering core software development principles.

---

## 📌 Project Information

- **Repository Name:** `java-proyectos`
- **Subject Area:** Programming / Software Development
- **Main Technology:** Java (JDK)
- **File Format:** `.java`
- **Hosting Platform:** GitHub

---

## 🎯 Objectives

The main objectives of this repository are:

- Understand the syntax, structure, and logic of the Java programming language.
- Implement object-oriented programming principles (classes, objects, methods, inheritance, etc.).
- Develop algorithmic thinking and problem-solving skills through code.
- Write clean, well-commented, and properly structured Java programs.
- Practice handling standard input/output, data structures, and control flow.
- Maintain good version control habits using GitHub to track project progress.

## ▶️ How to Use This Repository

1. Open the repository on GitHub.
2. Select the Java file you want to review.
3. Open the file to inspect its source code.
4. Download or clone the repository to work with the files locally.

To clone the repository using Git, run:

```bash
git clone https://github.com
```

Then, navigate to the project directory:

```bash
cd java-proyectos
```

To compile and run a specific Java file from the terminal (e.g., `Uno.java` inside `Practicas_java/`):

```bash
cd Practicas_java
javac Uno.java
java Uno
```

## ✅ Best Practices

The following practices are encouraged throughout the development of the assignments:

- Follow Java naming conventions (PascalCase for classes, camelCase for methods/variables).
- Maintain proper indentation and clear code formatting.
- Write explanatory comments for complex methods or logic blocks.
- Ensure proper use of data types and variable scopes.
- Handle exceptions and errors gracefully if required.
- Use descriptive and consistent file names matching the public class name.
- Save changes and maintain an organized commit history using GitHub.
